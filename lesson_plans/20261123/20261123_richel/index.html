    I read at the Bianca technical summary that

    • 148 (ordinary/thin) compute nodes
    • 10 fat compute nodes
    • 27 GPU nodes

    So around 17% of all Bianca nodes are GPU nodes.

    Bianca works differently on GPU nodes:

    [richel@sens2025560-bianca richel]$ nvidia-smi
bash: nvidia-smi: command not found

    Let's try an interactive session:

    [richel@sens2025560-bianca richel]$ interactive -A sens2025560 -C gpu
You receive the high interactive priority.
You may run for at most 12 hours.
Please note that in 12 wallclock hours this interactive job will use 192 core hours.

Please, use no more than 14 GB of RAM.

Waiting for job 669 to start...
^CKilling program 669...

    OK, let's specify one GPU per node:

    [richel@sens2025560-bianca richel]$ interactive -A sens2025560 -C gpu --gpus-per-node=1
You receive the high interactive priority.
You may run for at most 12 hours.
Please note that in 12 wallclock hours this interactive job will use 192 core hours.

Please, use no more than 14 GB of RAM.

Waiting for job 670 to start...

    Hence:

    • -C gpu is identical to -C gpu --gpus-per-node=1
    • By default, when you book a GPU, you get 1
    • 1 GPU hour is 16 CPU hours
